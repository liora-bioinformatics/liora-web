R package · Inferential statistics

MKinfer

Inferential statistics for real-world data — bootstrap, permutation, and imputation-based tests with clear visualizations.

Built with
View on GitHub View on CRAN

Key features

  • Bootstrap, permutation, and Hsu t-tests plus intersection–union tests
  • Multiple-imputation t- and Wilcoxon tests for incomplete data
  • Volcano, Bland–Altman, and mean–difference plots

About

MKinfer provides a broad set of inferential methods — including bootstrapped confidence intervals and a range of robust and exact test procedures — developed and maintained by Prof. Matthias Kohl. It runs on R 4.0 or newer.

Installation

> install.packages("MKinfer")
