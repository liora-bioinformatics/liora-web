R package · Robust estimation

robrmx

Radius-minimax (RMX) estimators — optimally robust estimation for parametric models.

Built with
View on GitHub

Key features

  • Asymptotically linear estimators for infinitesimal neighborhoods
  • Finite-sample corrections and diagnostic plots
  • Reliable estimates under model deviations and outliers

About

robrmx implements radius-minimax estimators, a class of optimally-robust procedures (Kohl 2005; Rieder et al. 2008), with diagnostics and finite-sample corrections. Development version on GitHub.

Installation

> remotes::install_github("stamats/robrmx")
